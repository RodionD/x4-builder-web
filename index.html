Планировщик станций X4: Foundations

Укажите папку установленной игры — ту, где лежат 01.cat … 09.cat и папка extensions (в Steam: …/steamapps/common/X4 Foundations). Данные читаются прямо в браузере, никуда не отправляются.

Браузер не даёт выбрать папку (Windows: игра в Program Files — «содержит системные файлы»)? Открыть её как набор файлов — работает везде, но папку придётся выбирать при каждом открытии.

Этот браузер покажет окно «загрузить файлы»: файлы не загружаются в сеть, браузер только даёт странице их прочитать. Запомнить папку он не умеет: её придётся выбирать при каждом открытии (в Chrome, Edge, Opera, Яндекс.Браузере папка запоминается).
